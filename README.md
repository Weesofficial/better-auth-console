# better-auth-console

> **In development.** This version is a name placeholder and contains no code yet. Don't install it.

A self-hosted admin console for [Better Auth](https://better-auth.com). It runs inside your own app and reads your own database, so no user data leaves it.

- Users, sessions, bans and lockouts
- Security event feed (from [better-auth-shield](https://github.com/Weesofficial/better-auth-shield))
- Organization and tenant views when those plugins are installed

Design: [better-auth-shield/docs/design.md](https://github.com/Weesofficial/better-auth-shield/blob/main/docs/design.md)
